# Clasificación de datos

`PUBLIC_OFFICIAL` identifica una publicación oficial que puede redistribuirse después de verificar sus condiciones. `RESTRICTED_SOURCE` identifica material recibido o conservado con acceso limitado. `PRIVATE_RAW` identifica bytes originales de adquisición. `BRONZE_2_CANDIDATE` es un derivado pendiente de revisión. `BRONZE_2_PUBLIC` es un artefacto aprobado para publicación. `SYNTHETIC_FIXTURE` solo se usa en pruebas y nunca cuenta como observación oficial.

La detección combina nombres de campos, valores, texto libre, metadatos y rareza de combinaciones. Una columna no se publica solo porque no coincida con una lista conocida.
