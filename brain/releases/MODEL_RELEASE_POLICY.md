# Política de modelos publicados

Cada release de pesos debe incluir versión, formato, checksum, licencia, arquitectura, requisitos, dataset Bronce 2.0 utilizado, receta de entrenamiento, métricas, limitaciones, evaluación de memorización y Model Card. Los pesos no se incorporan al historial normal del código si superan el tamaño acordado; se distribuyen por el almacén de modelos/release con el mismo manifest.
