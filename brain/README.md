# Brain de AMP-CONT-AI

Este directorio contiene el plan, los contratos, la trazabilidad y la evidencia de la modernización. No contiene secretos, credenciales, datos originales, sesiones de navegador ni scrapers privados.

## Estados

- `PLANNED`: tarea definida, sin cambios ejecutados.
- `IN_PROGRESS`: ciclo LOOP ENGINEERING activo.
- `VERIFIED`: criterios de aceptación y evidencia revisados.
- `BLOCKED`: falta una condición externa documentada.
- `RELEASED`: incluido en una distribución pública aprobada.

La carpeta `brain/state/` es estado local y queda excluida de Git. Los documentos públicos solo pueden referenciar evidencia privada mediante identificadores y hashes.
