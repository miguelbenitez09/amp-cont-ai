# AMP-CONT-AI Bronce 2.0

Este directorio está reservado para datasets derivados y aprobados para publicación. No se deben copiar aquí archivos de `data/raw`, `data/bronze_original`, exportaciones de portales, manifiestos privados ni datos con identificadores directos.

Cada versión debe incluir:

- `DATASET_CARD.md` con cobertura, licencia, esquema y transformaciones.
- `manifest.json` con versión, conteos y SHA-256.
- un informe de revisión de privacidad y riesgo de reidentificación.
- un diccionario de datos y la lista de exclusiones.

La ausencia de un archivo de datos no representa una edición publicada. Los fixtures de pruebas se marcan como sintéticos.
